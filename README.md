# mployee-Salary-Prediction-Compensation-Analytics-End-to-End-ML-Project
End-to-end ML salary prediction &amp; HR analytics app built with Python, Scikit-Learn, and Streamlit (R²: 0.9079, MAE: ₹2.71 LPA). Combines outlier-robust Huber Regression with 80% quantile prediction intervals, career what-if simulation, and automated batch payroll equity auditing.
